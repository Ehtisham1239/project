# Download the OQC website project

Open **OQC-Website-Project.zip** in this repository and choose **Download raw file**. The archive is approximately 3.1 MB and contains the source, migrations, pinned dependencies, tests, branding, setup instructions and QA reports.

Extract the archive, then read `OQC-Website-Project/DOWNLOAD_README.md`. The web application is under `oqc/`. No default administrator or real business records are included. Local secrets, dependencies, build output and database backups are excluded. Configure your own environment and create the first administrator interactively.

The companion `.sha256` file verifies the archive's checksum. Approved owner content, legal review, hosting/storage configuration and staging validation remain necessary before a live launch.
